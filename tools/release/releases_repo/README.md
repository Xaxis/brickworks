# Brickworks downloads

The built packages of [Brickworks](https://brickworks.diy), a free CAD for LEGO® models, for
Linux, macOS and Windows. Each release here holds the packages a version shipped and their
`SHA256SUMS`. This repository holds builds only.

Get Brickworks from **[brickworks.diy/download](https://brickworks.diy/download)**: it picks the
right package for your system, shows its size and checksum, and says how to install it. What
changed in each version is on [brickworks.diy/changelog](https://brickworks.diy/changelog). The
same builder runs in a browser at [brickworks.diy/app](https://brickworks.diy/app), with nothing
to install.

The builds are not signed yet: macOS asks you to choose Open Anyway, and Windows' SmartScreen to
choose More info, then Run anyway.
