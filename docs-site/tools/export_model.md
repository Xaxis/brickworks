```text
Write the model out as File, Export does, where Export writes (the Downloads folder; a download on the web): format ldraw (.ldr, or .mpd with its sub-models, with its build steps), studio (a BrickLink Studio .io), a 3D file at real size — glb (one file: Blender, three.js, AR; any size of model), gltf (the same as text), obj (with an .mtl of its colours) or stl (one mesh in mm, Z up, to 3D print) or 3mf (to 3D print in colour: an object a colour, in mm on the bed); obj, stl and 3mf hold every triangle and are capped — picture (.png), bricklink (a wanted list), rebrickable (a parts list .csv), pickabrick (LEGO® Pick a Brick's list: element numbers and quantities, 400 lines a file; the answer names the parts with no element number known), or instructions (the building instructions as a booklet to print), or pdf (the same booklet as the PDF the Instructions window prints: its own fonts carried, every letter as typed; the answer names any its type cannot print, and shows its cover as the PDF prints it); all_models is every model the person saved, as LDraw in one .zip (File, Export, All my models). studio, picture, instructions and pdf are jobs: the answer is a job number at once, and job gives the result. A bricklink wanted list takes condition, wanted_list and notify, as BrickLink's upload reads them; what is not given is what the person chose last on the parts list's BrickLink button. Nothing is uploaded: the person uploads the file. With format ldraw, submodels=true writes each sub-model as an LDraw file of its own, with its own sub-models and steps, all in one .zip (File, Export, Each sub-model), and submodel= just the one of that name in the model tree, as its row's menu does. stl and 3mf answer whether each object is a closed solid, as a slicer needs it, from the check each object's mesh is given, and name any part that is not. Nothing is written over: a file of that name already there is kept, and the new one takes the next free name (pods_2.3mf), which the answer gives. Only the person does these, from the window's menus, each theirs to decide, so no tool does them; a session sends the person to them by name and where, and never says they cannot be done. Build together (File › Build together…): someone else builds this model with the person at the same time, live, from their own computer or browser, by a link the person starts there and sends them; each sees the other's changes, pointer and chat, with an undo of their own. Share (File › Share…): a link anyone can open to see the model, its steps and its parts list, and in the public gallery if the person ticks it. Import (File › Import): a model file from their computer, LDraw, a Studio .io or an LDD .lxf, or a 3D model to brickify. Comments (File › Comments…, or a part's right-click menu, Comment on it…): a note pinned to a part for the people who build the model with them.
```
