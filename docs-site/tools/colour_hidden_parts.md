```text
Colour the parts nobody sees in the finished model, as big sets are coloured inside so a builder can tell where they are, as Tools, Colour the hidden parts… does. Hidden is measured, never guessed: the model drawn from 128 sides, every part its own colour, and only parts seen from none of them change. mode: sections (the booklet's: the assemblies a design named), stages (the build cut into stages= stages, as bags are), left_right or front_back (the halves of a symmetrical build told apart). Each group gets one colour far from every colour seen, and each part only a colour it is made in. Without apply it changes nothing and shows the inside cut open, coloured. Offer it at the end of a big model built in sections, never by default: apply=true with agreed=true only once the person has said yes; a model from a real set also needs set_agreed=true. One step to undo; the booklet shows each colour where its group starts.
```
