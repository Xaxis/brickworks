Every key, click and gesture Brickworks answers to. In the app the same list is **Help › Keys and controls** ([[F1]]), with a box to search it. This page is made from that list and from the menus' keys, so it says exactly what the app does.

![The app's keys sheet: a search box, then the keys for the mouse, the view and placing parts, each drawn as keys beside what it does.](/docs/img/shortcuts-keys.webp "Help › Keys and controls (F1): the same list as this page.")

These are the app's own keys. To use BrickLink Studio's, Mecabricks' or LDCad's instead, or to set your own, see [Your own keys](/docs/panels-and-settings#keys).

> [!NOTE]
> On a Mac, press Cmd wherever this page says Ctrl.
