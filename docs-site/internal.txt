# no docs page covers it: how the project is tested, measured, built and

# feature that is in no docs page and not here. One a line: a feature id, or
# entry:<a glob of where it lives>, then two spaces, a # and why.
#
# A tool a person does run (the MCP bridge, brick.py, the app's own command
# line) is in the docs, not here.
