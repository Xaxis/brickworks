D’où viennent ces données

Les informations, la liste de pièces et l’image de chaque set viennent de Rebrickable (les images sont conservées ici pour que votre navigateur ne les lui demande jamais), et ses pièces sont dessinées par Brickworks. Ceux marqués 3D sont montrés construits : des modèles que quelqu’un a construits dans LDraw, pièce par pièce, pour l’Official Model Repository de LDraw, et partagés sous une licence Creative Commons qui permet à chacun de les utiliser à condition de créditer leur auteur : chaque carte et chaque page nomme la personne qui l’a modélisé et renvoie à sa page là-bas. Dans l’application, les modèles 3D sont dans Fichier › Bibliothèque… ; un set ouvert depuis celle-ci garde son crédit quand vous le partagez.
