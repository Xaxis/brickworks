Téléchargement gratuit jusqu’à l’ouverture de Pro, après quoi les nouvelles versions viendront avec Pro. Chaque version que vous téléchargez continue de fonctionner, avec ou sans Pro.

La première version de bureau est en route. D’ici là, ouvrez l’application web.

La liste des téléchargements ne s’est pas chargée. Toutes les versions sont sur GitHub.

Premier lancement
  1. Ouvrez le zip et faites glisser Brickworks dans Applications.
  2. Ouvrez-le. macOS indique qu’il ne peut pas vérifier l’absence de logiciel malveillant : choisissez Terminé.
  3. Ouvrez Réglages Système, puis Confidentialité et sécurité. Sous Sécurité, choisissez Ouvrir quand même à côté de Brickworks, puis Ouvrir.

macOS le demande parce qu’Apple n’a pas encore notarié cette version. Il ne le demande que la première fois.

Si macOS dit que Brickworks est endommagé, c’est l’attribut de quarantaine du téléchargement, pas un vrai dommage. Vérifiez le téléchargement, puis, dans Terminal :

xattr -dr com.apple.quarantine /Applications/Brickworks.app

  1. Faites un clic droit sur le zip et choisissez Extraire tout. Brickworks ne se lance pas depuis l’intérieur du zip.
  2. Ouvrez le dossier et lancez Brickworks.exe.
  3. Si Windows affiche Windows a protégé votre ordinateur, choisissez Informations complémentaires, puis Exécuter quand même. Il ne le demande que la première fois, car cette version n’est pas encore signée.

Dans votre gestionnaire de fichiers, ouvrez les Propriétés de l’AppImage et autorisez son exécution comme programme. Puis double-cliquez dessus. Ou, dans un terminal :

chmod +x Brickworks-*.AppImage && ./Brickworks-*.AppImage

L’application ne démarre pas ? Il manque peut-être FUSE à votre système. Prenez plutôt le .tar.xz, et lancez-la depuis l’endroit où il se décompresse :

tar -xf Brickworks-*.tar.xz && ./Brickworks-*/brickworks.x86_64

Vérifier le téléchargement

Le SHA-256 de chaque fichier figure dans SHA256SUMS sur la version publiée sur GitHub.
