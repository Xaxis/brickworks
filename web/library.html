Who made these

Each is a model of a real set that somebody built in LDraw, piece by piece, for LDraw’s Official Model Repository, and shared under a Creative Commons licence that lets anyone use it as long as they credit them. Every card and page names who modelled it and links to its page there. In the app, the same shelf is File › Library…; a set opened from it keeps its credit when you share it.
