                        1. Open Google Cloud › Google Auth Platform, Get started: app name Brickworks, External, publish it.
                          2. 
                  
                        2. Clients › Create client › Web application, named Brickworks.
                          3. 
                  
                        3. Authorized redirect URI: https://brickworks.diy/auth/callback/google
                          4. 
                  
                        4. In Vercel › Environment Variables, Production: paste the Client ID as GOOGLE_CLIENT_ID and the secret as GOOGLE_CLIENT_SECRET.
                          5. 
                  
                        5. Redeploy production, then come back: Google turns on here.
                          6.

                        1. Open GitHub › Developer settings › New OAuth App.
                          2. 
                  
                        2. Name Brickworks, homepage https://brickworks.diy.
                          3. 
                  
                        3. Authorization callback URL: https://brickworks.diy/auth/callback/github, then Register.
                          4. 
                  
                        4. Generate a new client secret. In Vercel › Environment Variables, Production: the Client ID as GITHUB_CLIENT_ID, the secret as GITHUB_CLIENT_SECRET.

                        Phones
                        
            
                        
              
                        What a phone is told before the studio opens, on this site, from
                what was measured on phones (docs/PHONE.md). Pages read a change within a minute or two.
                        
              
              
                        A model past it asks first on a phone, from its page: "About N parts: on a phone this may
                close the tab". Computers and tablets are never asked.
                        
              
              
                        A first visit on a phone is told how long it will take as it loads: the files at the rate
                they are coming, then these seconds.

                        Claude
                        
            
                        Claude on your own Anthropic key, in the panel beside every section: it reads what the console
              reads, and on the social desk it suggests posts and replies as drafts. It never sends, posts, replies, schedules,
              deletes, mails, or changes a plan or a switch: you do, from the drafts.
                        
          
                        
          
                        
          
                        The checks' own pool (?tests=1): its Anthropic is a stand-in on this
            server, and only the stand-in's key fits. Nothing here reaches Anthropic.
                        
          
                        
            
                        
              
                        Your API key
                        
              
                        
              
                        
              
              
                        Made at console.anthropic.com › API keys, and paid for by you, there. It is checked
                with Anthropic, then kept on the server alone, sealed: it is never shown again, here or anywhere, only its last four
                characters.
