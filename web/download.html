Brickworks for your desktop

The same builder as the web app, with all 28,319 parts on disk, so building, saving and the instructions work with no network at all. Free, for Linux, macOS and Windows.

Download

Brickworks for the desktop runs on Linux, macOS and Windows. On this device, the web app is the way in; every download is below for a computer.

The first desktop release is on its way. Until it is out, Brickworks runs in your browser: open the app.

Every download

Starting it

The AppImage is one file that runs as it is:

chmod +x Brickworks-*.AppImage && ./Brickworks-*.AppImage

Or allow it to run as a program in your file manager's Properties, then double-click it. AppImages mount themselves with FUSE; a system without it can add --appimage-extract-and-run, or use the .tar.xz:

tar -xf Brickworks-*.tar.xz && ./Brickworks-*/brickworks.x86_64

What it needs

  • 64-bit x86 Linux
  • A graphics driver with Vulkan; OpenGL 3.3 works where there is none

Checking the download

sha256sum Brickworks-*.AppImage

The answer should be the SHA-256 shown above.

Starting it

Open the zip, then move Brickworks.app into Applications. One app runs on both Apple silicon and Intel Macs.

The first launch asks first. This build is not yet notarised by Apple, so macOS will not open it on a double-click the first time:

  1. Open Brickworks. macOS says it cannot check it for malicious software: choose Done.
  2. Open System Settings, then Privacy & Security, scroll to Security and choose Open Anyway beside Brickworks.
  3. Choose Open. From then on it opens like any other app.

If macOS says the app is damaged, that is the download's quarantine flag on an app Apple has not notarised, not damage. Check the SHA-256 first, then in Terminal:

xattr -dr com.apple.quarantine /Applications/Brickworks.app

What it needs

Checking the download

shasum -a 256 ~/Downloads/Brickworks-*.zip

The answer should be the SHA-256 shown above.

Starting it

Right-click the zip and choose Extract All, then run Brickworks.exe from the folder. It has to be extracted first: the part library, Brickworks.pck, sits beside the program and is not found from inside the zip.

The first launch asks first. This build is not yet signed, so Windows may say "Windows protected your PC". Check the SHA-256, then choose More info and Run anyway. Windows remembers after the first time.

What it needs

  • 64-bit Windows 10 or 11
  • A graphics driver with Vulkan or Direct3D 12; OpenGL 3.3 works where there is neither

Checking the download

In PowerShell:

Get-FileHash .\Downloads\Brickworks-*.zip -Algorithm SHA256

The answer should be the SHA-256 shown above.
